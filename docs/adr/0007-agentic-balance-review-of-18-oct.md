# ADR-0007: Agentic balance (review of 18 Oct)

**Status:** Proposed (requirement-level, D07)  
**Date:** 2026-10-18

## Context

A review found the requirements were workflow-centric while agentic capability is the reason for the project.

## Decision

Add six Mandatory agentic capability outcomes (M29 to M34), one scenario (S8) and six tests; promote minimum production quality monitoring and model choice; add long-term memory as High priority.

## Consequences

Adds M29 to M34 (planning, tools and knowledge, multi-agent, interactive human-agent work, production quality monitoring, model choice), scenario S8 and tests T34 to T39, and long-term memory as High priority.
