# ADR-0004: Optional administrator assistant

**Status:** Proposed (requirement-level, D04)  
**Date:** 2026-10-18

## Context

An embedded assistant for administrators is useful but adds an agent with operational reach.

## Decision

UI assistant optional; when used all agent operations must be authorized and audited.

## Consequences

The assistant is Optional (O01). When enabled, every action it takes must be authorized and audited.
