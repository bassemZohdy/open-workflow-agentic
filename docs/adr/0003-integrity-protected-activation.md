# ADR-0003: Integrity-protected activation

**Status:** Proposed (requirement-level, D03)  
**Date:** 2026-10-18

## Context

Definitions, prompts and model routes change behavior. Activation needs integrity and audit, but teams use different signing and delivery tools.

## Decision

Accept suitable versioned, verified and audited publication; no prescribed signature transport.

## Consequences

Any versioned, verified, audited publication path is acceptable. No signature transport is prescribed.
